# Список ключевых слов для модерации (по одному на строку).
#
# Синтаксис:
#   слово      — совпадение только с целым словом («бля» не сработает на «рубля»);
#   слово*     — слово, начинающееся с «слово» (бляд* → блядь, блядский);
#   *слово*    — слово, содержащее «слово» в любом месте;
#   два слова  — фраза: слова через любое количество пробелов;
#   !шаблон    — исключение: слова, подходящие под шаблон, никогда не считаются нарушением;
#   # ...      — комментарий.
#
# Регистр, «ё/е», латинские буквы-двойники внутри кириллических слов (xуй → хуй),
# «цифры вместо букв» (6ля → бля) и растянутые буквы (бляяять → блять) нормализуются автоматически.
# Путь к файлу задаётся переменной MODERATION_KEYWORDS_FILE, дополнительные слова — MODERATION_KEYWORDS.
